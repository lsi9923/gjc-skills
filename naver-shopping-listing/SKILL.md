# 네이버쇼핑 상품등록 실전 컴퓨터 유즈(Computer Use) 프로토콜

> **[필수 원칙: 더미 파일 / 모의 JSON 생성 절대 금지]**  
> 사용자가 상품등록을 요청했을 때 모의 JSON이나 복사-붙여넣기용 텍스트만 출력하고 작업을 끝내는 것은 엄격히 금지된다.  
> 본 스킬은 **Orca Computer Use (`orca computer`)**를 사용하여 실제 Chrome 브라우저의 소싱 페이지를 읽고, 네이버 스마트스토어 센터 등록 화면에 직접 입력·제어하는 **실행형 자동화 스킬**이다.

---

## 0. 알고리즘 전제 (판단의 기준선)

```text
최종 랭킹 = [적합도 (진입 장벽)] + [인기도 (순위 결정력)] − [신뢰도 감점]
```

- **GBDT는 전환율 공식이 아니다.** 2022년 도입된 GBDT의 본질은 검색어–상품 적합도가 기준치 미만이면 클릭·판매량이 아무리 높아도 상위 노출에서 잘라내는 **컷오프 필터**다.
- **적합도가 0이면 인기도 100만 점도 1페이지 진입 불가.** 따라서 작업 순서는 항상 적합도 → 신뢰도 → 인기도.
- 적합도 가중 서열: **카테고리(절대적) > 상품명(핵심) > 스토어명 > 브랜드/제조사 ≫ 속성·태그(미미), 이미지 0%**
  - 이미지는 적합도 점수와 **무관**. 워터마크·텍스트 과다·해상도 미달을 거르는 품질 필터일 뿐 가산점이 없다.

## 1. 컴퓨터 유즈(Computer Use) 4단계 자동 등록 파이프라인

### 1단계: 활성 브라우저 소싱처 실시간 분석 (`orca computer`)
1. `orca computer list-windows --app chrome --json`으로 현재 띄워진 소싱 탭 확인.
2. `orca computer get-app-state --app chrome --restore-window --json`으로 1688/타오바오 상세페이지 접근성 트리 및 스펙 직접 추출 (봇 차단 418 우회).
3. 실시간 공급단가(CNY), 제품명, 소재, 치수, 중량, 옵션, 대표 이미지 URL 확보.

### 2단계: 20대 카테고리 relevance & 25~30자 상품명 설계
시스템 파이프라인 스크립트(`run_pipeline.py`)를 통해 동적 계산:
- **카테고리 relevance 1.0**: 20대 법정 카테고리 중 최고점 경로 확정.
- **상품명 25~30자**: 메인키워드 좌측 0번 배치, 중복 배제, terms 검증 통과(✓).
- **판매가 계산**: `실공급가(CNY) × 환율(200) + 배송비(3,500원) / (1 - 마진율 0.35)` 자동 산출.
- **태그 10개**: 카테고리별 맞춤형 무중복 10개 태그 도출.
- **고시정보**: 품목군별 10대 법정 항목 100% 실측치 주입 (상세참조 0건).

### 3단계: 스마트스토어 센터 화면 직접 입력 및 조작 (`orca computer`)
Chrome에서 스마트스토어 센터 상품등록 페이지(`https://sell.smartstore.naver.com/#/products/create`)를 직접 조작한다:
1. `orca computer get-app-state --app chrome --restore-window --json`으로 요소 인덱스 확인.
2. 각 항목 직접 제어:
   - 카테고리 검색/선택 (`orca computer click` -> `set-value` -> 선택)
   - 상품명 입력 (`orca computer set-value` 또는 `paste-text`)
   - 판매가 / 정상가 / 재고수량 주입
   - 옵션 설정 (단독형/조합형 옵션명 및 옵션값 입력)
   - 대표 이미지(1000×1000) 등록
   - 상세설명 스토리보드 HTML 주입
   - 상품 주요정보 (모델명, 브랜드, 원산지, 상품상태)
   - 10대 법정 고시정보 세부 항목 입력
   - 배송비 (기본 3,500원 / 반품 3,500원 / 교환 7,000원)
   - 10개 태그 순차 입력

### 4단계: 쇼핑 상품정보 검색품질 체크 및 검증
1. 하단 [쇼핑 상품정보 검색품질 체크] 버튼 클릭.
2. 점검 통과 상태 확인 후 등록 완료 화면을 사용자에게 보고.

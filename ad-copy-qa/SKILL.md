# 광고 카피 QA 스킬

광고 카피를 제출하기 전 아래를 자가 검수하고, 결과를 체크리스트로 함께 보여준다.

- [ ] 매체 정책 위반 표현 없음 (체중감량 약속·의학 효능·과장 보증 금지)
- [ ] 소구 1개에 집중 (한 카피에 여러 약속 금지)
- [ ] 약속에는 근거가 붙어 있다 (성분·숫자·리뷰)
- [ ] 타깃이 3초 안에 자기 얘기로 인식할 훅인가
- [ ] 글자수: 헤드라인 한글 20자 내외

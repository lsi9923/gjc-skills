# 알려진 오류 및 해결 교훈 (Known Errors & Lessons)

## 2026-10-16 쿠팡 Wing 상세/이미지 저장
- 증상: 회전 아이콘(로딩 인디케이터)이 남아 있는 상태에서 중간저장을 실행하여 상세 이미지가 0장으로 저장됨.
- 원인: 이미지 업로드 후 내부 변환/렌더링이 완료되기 전에 모달 창 닫기 또는 저장 요청이 트리거됨.
- 해결: 업로드 회전 아이콘이 0개이고 창 저장 버튼이 활성화된 것을 확인한 뒤 창 저장을 누르고, 본화면의 반영 이미지 수를 확인한 뒤에만 중간저장을 진행한다.
- 확인 기준: 회전/로딩 인디케이터 0개 + 상세 모달 창 저장 완료 + 본화면 반영 이미지 카운트 일치.

## 2026-10-16 쿠팡 Wing 대표이미지 업로드
- 증상: 업로드 요청이 HTTP 200 성공을 반환했음에도 실제 판매자 등록 폼에 대표이미지가 미반영됨.
- 원인: 네트워크 응답 완료와 프론트엔드 폼 상태 업데이트(state synchronization) 간의 타이밍 갭.
- 해결: HTTP 응답만 보지 말고 실제 폼 UI 상태를 검증한다. +버튼이 없는 상태(hasPlus === false)는 이미지가 이미 채워진 정상 신호이므로 중복 재업로드를 하지 않는다.
- 확인 기준: 예상 노출 화면 썸네일이 실제 이미지로 렌더링되고 빨간색 "대표이미지 항목을 입력해 주세요" 경고 문구가 완전히 소멸됨.

## 2026-10-16 쿠팡 Wing 대표이미지 filechooser 타임아웃
- 증상: 클릭 후 filechooser 대기 방식 사용 시 이벤트 타임아웃 발생.
- 원인: 브라우저 보안 및 비동기 이벤트 핸들링 차이로 OS 레벨 파일 선택 창 이벤트가 감지되지 않음.
- 해결: 클릭→filechooser 대기 방식 대신 대표 박스 컨테이너 내부의 input[type=file] 요소를 직접 찾아 setInputFiles로 파일 경로를 주입한다(추가이미지 업로드 성공 방식과 동일).
- 확인 기준: filechooser 이벤트 대기 없이 DOM 레벨 input에 파일 즉시 세팅 및 미리보기 생성.

## 2026-10-16 공통 저장 가드 누락
- 증상: 이미지 또는 필수 항목의 업로드 결과가 0건인데 다음 단계 저장 로직이 그대로 실행됨.
- 원인: 업로드 성공 여부 검증 없이 순차적으로 저장 함수를 호출하는 무조건 실행 구조.
- 해결: 모든 저장 실행 코드는 필수 확인 조건이 true일 때만 진입하도록 명시적인 if 가드를 적용한다.
- 확인 기준: 저장 실행 전 업로드 건수 > 0 및 필수값 유효성 검증 통과 여부 boolean 확인.

## 2026-10-16 Aside REPL 세션 경로 거부
- 증상: setInputFiles 실행 시 "escapes the session directory" 에러로 업로드 거부.
- 원인: Aside REPL을 one-shot(일회성)으로 호출할 때마다 매번 임의의 sessionDir이 새로 생성되어, 세션 디렉터리 외부 경로의 파일 접근이 차단됨.
- 해결: 지속적인 Aside REPL 세션 하나를 유지하고, 출력된 sessionDir 내부(sessionDir/assets/...)로 필요한 자산을 복사한 뒤 SHA256 대조를 거쳐 해당 세션 내부 경로로 업로드를 실행한다.
- 확인 기준: setInputFiles 대상 파일 경로가 현재 활성 REPL의 sessionDir 내부 절대 경로와 일치.

## 2026-10-16 네이버 SmartEditor ONE 다중 업로드 실패
- 증상: SmartEditor ONE에서 8장을 동시에 업로드하면 전부 "알 수 없는 오류" 발생 (1.46MB 파일도 실패하므로 단순 파일 용량 문제가 아님).
- 원인: 에디터 내부 업로드 버퍼 및 에디터 프레임워크의 동시 멀티파일 비동기 처리 오류.
- 해결: 에디터 본문 내 실제 input[type=file]을 타겟팅하여 section_01 1장 시험 업로드(POST 2xx 응답, 전송중 인디케이터 0, src pstatic 반영) 성공을 확인한 뒤 02~10을 1장씩 순차 업로드하고, 10장 확인 후 에디터 상단 "등록" 버튼을 클릭한다.
- 확인 기준: 1장 시험 업로드 성공 확인 → 1장씩 순차 업로드 완료 → 에디터 내 10장 pstatic 이미지 정상 배치 및 "등록" 클릭 완료.

## 2026-10-16 쿠팡 Wing 옵션 및 노출상품명 규격
- 증상: 카테고리 매핑 시 옵션 속성이 맞지 않거나, 옵션행의 정상가/재고가 "-"로 비어 저장이 거절되거나, 노출상품명에 브랜드가 중복 표기됨.
- 원인: 쿠팡 카테고리별 고정 옵션(색상/수량) 속성 강제, 계산된 가격/재고 미입력, 쿠팡 자동 브랜드 접두어 규칙 미인지.
- 해결: 카테고리가 색상/수량 고정이면 자유 "구성"을 쓰지 않고 출처값에 매핑(예: P1 블루 / 1세트)한다. 옵션 테이블 행의 정상가·재고가 "-"로 비어 있지 않은지 저장 전에 반드시 검증한다. Wing 노출상품명에는 브랜드(끄롱마제)를 직접 삽입하지 않는다(미리보기/전시 시 자동 부착됨).
- 확인 기준: 옵션행 정상가·재고 숫자 필수 입력 확인 + 노출상품명 27자 내외 브랜드 중복 없음 확인.

## 2026-10-16 재오픈 감사 시 렌더링 지연 및 캡처 불일치
- 증상: 재오픈 감사 시 title이 빈값으로 읽히거나, 캡처 파일명과 실제 화면의 마켓·상품명이 불일치함.
- 원인: SPA(Single Page Application) 비동기 DOM 로딩 미완료 상태에서 빠른 조회 시도, 수집 파일명 라벨링 오차.
- 해결: 재오픈 후 상품명 텍스트가 실제로 표시될 때까지 대기한 후 1회 확인한다. 캡처 저장 시 파일명과 실제 화면 속 마켓 및 상품명 텍스트가 정확히 일치하는지 대조한다.
- 확인 기준: DOM 상품명 input/heading 렌더링 완료 후 감사 실행 + 캡처 파일명과 화면 내 상품명 일치 확인.
## 2026-10-16 쿠팡 Wing 대표이미지 감사 및 옵션행 확인
- 증상: 대표 업로드 XHR 200·중간저장 후 재오픈 시 img 셀렉터로 repImgCount=0인데 빨간 대표 오류와 + 버튼은 없음.
- 원인: 대표 박스는 img 태그 대신 CSS background-image 등으로 렌더링되어 단순 img 태그 개수 검사가 오탐을 유발함.
- 해결: 컨테이너 요소 스크린샷 + computed backgroundImage 및 img src를 수집하여 https URL 존재 여부로 판정하고 재업로드 반복을 금지한다. Wing 옵션행 정상가·재고는 별도 입력해야 하며 표에 "-"면 미입력이므로 저장 전 31,900/26,800/999처럼 표 내부 실제 입력값을 반드시 확인한다.
- 확인 기준: 대표 박스 내 https 이미지 URL 존재 + 빨간 오류 없음 + 옵션행 정상가·재고 수치 입력 확인.

## 2026-10-16 네이버 SmartEditor ONE 사진 업로드 (미부착 임시 input)

  (B) Main world에서 HTMLInputElement.prototype.click을 래핑하여 임시 input을 document.body에 강제로 부착한 뒤 setInputFiles 실행 (DataTransfer 합성 이벤트 금지).
- 확인 기준: 전송중 인디케이터 0개 + 이미지 src pstatic 도메인 반영 확인 + 1장 시험 성공 후 1장씩 순차 업로드.

- 확인 기준: 전송중 인디케이터 0개 + 이미지 src pstatic 도메인 반영 확인.

- 해결: '브랜드 추가하기' 버튼 클릭을 엄격히 금지한다(외부 심사 등록 요청으로 이어져 작업 중단 위험). 브랜드 칸에 1회 정확히 재입력 시도 후에도 안 나오면 해당 칸을 빈칸으로 둔 채 중간저장하고, 확인표에 '미해결' 항목으로 명시하여 사용자 승인을 받는다.
- 확인 기준: 최종 등록/결과표의 미해결 항목에 브랜드 자동완성 미노출 이슈 기록 및 임의 브랜드 추가 요청 방지.

## 2026-10-17 쿠팡 Wing 카테고리 검색 선택 후 하위 폼 섹션 미렌더링
- 증상: 쿠팡 Wing 카테고리 검색창에서 추천 항목을 선택했으나 옵션, 상품고시 등 필수 하위 섹션이 열리지 않음.
- 원인: 최종 말단(Leaf) 카테고리가 아닌 상위/중간(Non-leaf) 카테고리를 선택하여 하위 입력 폼이 활성화되지 않음.
- 해결: 단순 검색어 추천의 상위 분류만 누르지 말고, 단계별 카테고리 트리 탐색기를 통해 실제 최하위 말단 리프(예: 고데기/매직기 > 여행용/휴대용 등)까지 도달하여 최종 선택한다.
- 확인 기준: 상품 등록 폼의 옵션 및 상품고시 섹션이 정상적으로 언폴드(펼쳐짐)되어 입력 가능한 상태로 표시됨.

## 2026-10-17 쿠팡 Wing 필수 옵션축 '모델명/품번' 삭제 불가 대응
- 증상: 쿠팡 Wing 옵션 등록 시 '모델명/품번' 옵션축이 필수로 강제되어 있으며, 삭제 컨트롤(휴지통 아이콘 등)이 없어 제거할 수 없음.
- 원인: 특정 카테고리(예: 가전/디지털)에 쿠팡 시스템 정책상 영구 바인딩된 고정 옵션축임.
- 해결: 1688 공장의 임의 모델번호나 제3자 원천 상품의 모델명을 그대로 넣지 않는다. 옵션 행을 0행 상태로 중간저장하고, 확인표에 자체 관리용 고유 모델코드(예: 끄롱마제 자체 코드) 결정을 사용자에게 요청하여 확정 후 입력한다.
- 확인 기준: 등록 확인표의 미해결 항목에 '모델명/품번 옵션축 결정 필요' 명시 및 임의 타사 모델번호 입력 방지.

## 2026-10-17 쿠팡 Wing 중간저장 배너/목록 열기 (Node is not an Element 에러)
- 증상: Wing 중간저장 배너 또는 중간저장 목록 열기 클릭 시 `Node is not an Element (text node)` 에러 발생.
- 원인: Playwright / 브라우저 자동화에서 DOM 요소 노드가 아닌 텍스트 노드의 `ElementHandle`을 대상으로 클릭을 시도함.
- 해결:
  1) `page.getByText(/중간저장 된 내용/).first()` Locator를 사용하여 클릭한다.
  2) Locator 클릭 실패 시: 해당 요소의 `boundingBox()`를 측정하여 중심 좌표로 `page.mouse.click(x, y)`를 실행한다.
- 확인 기준: 중간저장 목록 모달 창이 정상적으로 열리고, 내부에 저장된 행(`savedRows`)이 정상 표시됨.

## 2026-10-17 쿠팡 Wing 중간저장 초안 전환 경고창 (DOM 확인 모달 .alert-confirm)
- 증상: Wing 중간저장 행 선택 후 다른 초안으로 전환 시 `입력하신 정보는 저장되지 않습니다. 변경하시겠습니까?` 경고창에서 멈추거나 타임아웃 발생.
- 원인: `formV2.js` 내부 커스텀 DOM 모달(`w()`, `confirmButtonClass: "alert-confirm"`). 현재 폼이 수정된 상태(`!v().isEqual(oSellerProduct, oSellerProductSnapshot)`)에서만 표시되며, 폼 미수정 상태에서는 경고 모달 없이 즉시 `applyDraft`가 호출됨. 브라우저 네이티브 `window.confirm()`이 아니므로 `page.once('dialog')`는 무효함.
- 해결:
  1) `page.once('dialog')`를 사용하지 않는다 (네이티브 대화상자가 아니므로 리스너 동작 불가).
  2) 행 '선택' 클릭 후 조건부로 DOM 확인 모달의 버튼을 클릭한다:
     ```javascript
     const confirmBtn = page.locator('.alert-confirm');
     if (await confirmBtn.isVisible({ timeout: 1500 }).catch(() => false)) {
       await confirmBtn.click();
     }
     ```
  3) 폼이 미수정 상태여서 모달이 뜨지 않으면 대기 없이 즉시 다음 단계로 진행한다.
- 확인 기준: `draft-with-document-checksum?path=${path}` API 응답의 `oSellerProduct.sellerProductName`이 실제 폼에 로드된 상품명과 일치하는지 확인.

## 2026-10-17 Aside 브라우저 재부팅 후 메인 창 없음
- 증상: 시스템 재부팅 후 OmO 또는 브라우저 조작 에이전트가 `Aside u0 프로필에 브라우저 창이 없음` 오류로 조작 불가.
- 원인: Aside 백그라운드 프로세스는 떠 있으나 메인 GUI 창(`MainWindowTitle`)이 생성/활성화되지 않음.
- 해결: PowerShell에서 `Start-Process 'C:\Program Files\Aside\Application\Aside.exe'` 실행으로 창을 띄운 뒤 REPL에 재접속한다.
- 확인: `Get-Process Aside | Where-Object { $_.MainWindowTitle }` 로 MainWindowTitle 있는 창 존재 확인.

## 2026-10-17 Aside REPL openTab() 사용자 미노출
- 증상: `aside repl openTab()`으로 로그인 탭을 열었다고 보고했으나 사용자의 실제 화면(GUI)에는 탭이 보이지 않음.
- 원인: `aside repl` 탭은 보이지 않는 백그라운드 자동화 세션에 열리고 세션이 종료되면 소멸됨 (`listBrowserTabs` 빈 배열 반환). 사용자가 직접 볼 수 없어 로그인 불가.
- 해결: 사용자 로그인용 탭은 `aside repl openTab()`을 쓰지 않고, 보이는 창에 직접 열리도록 실행한다:
  `Start-Process 'C:\Program Files\Aside\Application\Aside.exe' -ArgumentList <URL들>`
- 확인: `Get-Process Aside | Where-Object { $_.MainWindowTitle }` 에 해당 사이트 제목이 정상 표시되는지 확인하고 사용자에게 최종 확인 요청.

## 2026-10-17 네이버 스마트스토어 '네이버 아이디로 새로 가입' 화면

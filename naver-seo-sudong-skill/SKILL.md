# 네이버 스마트스토어 상위노출 실전 컴퓨터 유즈(Computer Use) 등록 프로토콜

> **[필수 원칙: 더미 파일 / 모의 JSON 생성 절대 금지]**  
> 사용자가 등록을 요청했을 때 모의 JSON 파일(`SmartStoreListingPayload`)이나 복사-붙여넣기용 마크다운 텍스트만 출력하고 작업을 끝내는 것은 엄격히 금지된다.  
> 본 스킬은 **Orca Computer Use (`orca computer`)**를 사용하여 실제 Chrome 브라우저의 소싱 페이지를 읽고, 네이버 스마트스토어 센터 등록 폼에 직접 입력·제어하는 **실행형 자동화 스킬**이다.

---

## 0. 알고리즘 대원칙 (판단의 기준선)

```text
최종 랭킹 = [적합도 (진입 장벽)] + [인기도 (순위 결정력)] − [신뢰도 감점]
```

1. **GBDT는 컷오프 필터다.** 적합도가 기준치 미만이면 클릭·판매량이 아무리 높아도 상위 노출에서 완전히 잘린다.
2. **적합도가 0이면 인기도 100만 점도 1페이지 진입 불가.** (카테고리 1.0 만점 진입이 최우선)
3. **적합도 가중 서열:**  
   **카테고리(절대적) > 상품명(핵심) > 스토어명 > 브랜드/제조사 ≫ 속성·태그(미미), 이미지(가산점 0%)**
4. **상품명 5대 규칙 (25~30자 엄수):**
   - 완성형 메인 키워드는 맨 왼쪽 0번에 배치
   - 조합형 키워드는 간격을 좁게 유지
   - 조합형은 좌 → 우 순서 유지
   - 길이는 공백 포함 **25~30자 (최대 35자)** — 35자 초과 시 신뢰도/간소화 감점
   - 동일 키워드 중복 금지 (최대 1회만 허용)

## 1. 컴퓨터 유즈(Computer Use) 4단계 자동 등록 파이프라인

사용자가 상품 URL 또는 등록을 요청하면 다음 4단계를 즉시 자동 수행한다:

### 1단계: 활성 브라우저 소싱처 실시간 분석 (`orca computer`)
파이썬 백그라운드 스크립트만으로 1688/타오바오에 접근하면 봇 차단 및 로그인 세션 검증에 걸린다.  
따라서 사용자가 Chrome에 띄워둔 소싱 페이지를 `orca computer`로 직접 관측한다.
1. `orca computer list-windows --app chrome --json`으로 활성 Chrome 탭 및 창 확인.
2. `orca computer get-app-state --app chrome --restore-window --json`으로 현재 탭의 상품 상세페이지 접근성 트리 및 스펙 확인.
3. 실제 공급단가(CNY), 제품명, 소재, 치수, 무게, 옵션(색상/사이즈), 대표 이미지 URL 전수 추출.

### 2단계: 20대 카테고리 디스패치 & 실시간 SEO 계산
추출된 실측 스펙을 바탕으로 시스템 스크립트를 호출하여 동적 메타데이터를 확정한다:
```bash
python ~/.gjc/skills/naver-seo-sudong-skill/scripts/run_pipeline.py "<품목키워드>"
```
- **카테고리**: 20대 법정 카테고리 디스패처로 최적 경로 및 relevance 1.0 확정.
- **25~30자 상품명**: 메인키워드 좌측 0번 배치 및 terms 검증 통과 상품명 조합.
- **판매가 계산**: `실공급가(CNY) × 환율(200) + 배송비(3,500원) / (1 - 마진율 0.35)` 기반 자동 산출.
- **태그 10개**: 카테고리 전용 태그 풀 및 실측 연관검색어 기반 무중복 10개 엄선.
- **고시정보 10개**: 카테고리 맞춤형 법정 고시 항목 100% 실측치 주입 (상세참조 0건).

### 3단계: 스마트스토어 센터 화면 직접 입력 및 조작 (`orca computer`)
Chrome에서 스마트스토어 센터 상품등록 페이지(`https://sell.smartstore.naver.com/#/products/create`)를 조작한다.
1. `orca computer get-app-state --app chrome --restore-window --json`으로 등록 폼 요소 인덱스 확인.
2. 각 섹션별 자동 입력:
   - **카테고리 선택**: 카테고리 검색창 클릭 (`orca computer click`) -> 카테고리명 입력 (`orca computer set-value`) -> 검색 결과 선택.
   - **상품명 입력**: 상품명 입력란에 설계된 25~30자 상품명 주입 (`orca computer set-value` 또는 `paste-text`).
   - **판매가/재고**: 계산된 판매가 및 재고수량 입력.
   - **옵션 설정**: 단독형/조합형 옵션 선택 후 색상·사이즈 옵션값 입력.
   - **상품 이미지**: 대표 이미지(1000×1000) 업로드.
   - **상세설명**: 스마트에디터 ONE 열기 후 상세 스펙표 및 본문 작성.
   - **상품 주요정보**: 모델명, 브랜드, 원산지(중국), 상품상태(신상품).
   - **상품정보제공고시**: 카테고리 품목군 선택 후 10개 법정 항목 세부값 입력.
   - **배송비/반품비**: 일반배송, 기본 3,500원, 반품 3,500원 / 교환 7,000원.
   - **태그 10개 입력**: 검색설정 섹션에서 10개 태그를 하나씩 입력 후 확인.

### 4단계: 검색품질 체크 및 검증 완료
1. 스마트스토어 하단의 **[쇼핑 상품정보 검색품질 체크]** 버튼을 `orca computer click`으로 실행.
2. 상품명, 태그, 카테고리 품질 체크 통과(✓) 확인.
3. 등록 완료 또는 최종 검토 상태 화면을 사용자에게 보고.

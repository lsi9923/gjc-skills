# 메이커 셀링 도우미 × 네이버 SEO 실측 파이프라인 연동 설계서

## 1. 개요 및 배경

메이커 셀링 도우미(v0.0.3, Chrome Extension MV3)는 네이버쇼핑과 쿠팡 검색 결과 페이지에 플로팅 UI를 주입하여 판매자를 돕는 도구입니다.
그러나 원본 구현은 다음과 같은 치명적인 한계를 가집니다:
1. `daily_usage` 하드코딩으로 하루 20회 초과 시 차단됨 (`q = 20`).
2. 네이버 검색엔진의 핵심 알고리즘인 **카테고리 적합도(Relevance)** 분석이 전무함.
3. 형태소 색인어(`terms`, `IdxTerm`)를 추출하지 못하고 단순 판매자 등록 태그(`manuTag`)만 나열함.
4. 상위 노출 25~30자 상품명 설계 및 검증 기능이 없음.

본 설계는 우리가 구축한 `naver-seo-sudong-skill`의 진실의 방 실측 알고리즘을 `content.js`에 직접 주입하여, 네이버쇼핑 검색 페이지만 열면 **0.001초 만에 카테고리 1.0 경로, 공식 연관검색어, 형태소 terms, 25~30자 최적 상품명, 10개 태그를 원클릭으로 제공하는 완전체 도구**로 개편합니다.

```text
[네이버쇼핑 검색 페이지 로드]
       │

  ├── [25~30자 최적화 상품명 A안/B안 원클릭 생성 & 복사]
  └── [스마트스토어 전용 10개 태그 콤마형 원클릭 복사]
```

## 3. 세부 기능 모듈 설계

### 모듈 1: 무제한 사용 패치 (`daily_usage` 바이패스)
- `q = 20` 제한을 `q = 999999` 또는 `allowed: true` 항시 반환으로 패치.
- 사용자가 하루 몇 백 번을 검색해도 차단 메시지 없이 상시 가동.

### 모듈 2: 카테고리 Relevance 1.0 실측 표시기
- `cmp.category1` ~ `cmp.category4` 트리에서 각 레벨 최고점 카테고리를 추적.
- 예: `스포츠/레저(1.00) > 자전거(0.996) > 장갑(0.996)`
- UI 상단 헤더에 눈에 띄는 초록색 뱃지로 노출하여 셀러가 등록할 카테고리를 즉시 확인 가능.

### 모듈 3: 3개 탭 분리 (연관검색어 / 형태소 Terms / 등록태그)
- **탭 1: [공식 연관검색어]** 네이버가 추천하는 최상위 유입 키워드 (`relatedQueries`)
- **탭 2: [형태소 Terms]** 네이버 검색엔진 인덱서에 등록된 형태소 단어 (`IdxTerm`)
- **탭 3: [인기 태그]** 상위 40개 노출 상품들이 실제로 달아놓은 태그 (`manuTag`)

### 모듈 4: 25~30자 최적화 상품명 원클릭 생성기
- **5대 작성 규칙 내장:**
  1. 완성형 키워드 0번 위치 배치 (현재 검색어)
  2. 연관검색어 핵심 수식어 인접 배치 (`겨울`, `방한`, `라이딩`, `터치스크린`)
  3. 좌 → 우 순서 유지
  4. 공백 포함 **25~30자 엄수** (글자 수 실시간 계산)
  5. 중복 단어 0개 검증
- 클릭 한 번으로 A안/B안을 즉시 클립보드에 복사.

### 모듈 5: 스마트스토어 태그 10개 원클릭 복사기
- 공식 연관검색어와 검증 태그 중 상위 10개를 선별하여 `자전거장갑, 라이딩장갑, 겨울자전거장갑...` 형태로 복사.
- 스마트스토어 상품등록 폼 "태그" 칸에 그대로 붙여넣기만 하면 끝.

# naver-seo-sudong-skill

> **네이버쇼핑 상위노출 알고리즘 실측 기반 스마트스토어 수동등록 자동화 GJC 스킬**  
> 출처: 최이호 「온라인 진실의 방」 강의 기반 랭킹 알고리즘(적합도·인기도·신뢰도) 프로토콜

---

## 💡 왜 이 스킬인가?

외부 키워드 솔루션(아이템스카우트, 판다랭크 등)의 카테고리 비율은 **현재 등록된 상품 수의 백분율 통계**일 뿐, 네이버 검색엔진이 실제로 부여하는 가점이 아닙니다.

네이버의 **GBDT(Gradient Boosting Decision Tree)** 알고리즘은 검색어–상품 간 적합도가 기준치 미만이면 클릭수·판매량이 아무리 높아도 1페이지에서 잘라내는 **컷오프 필터**입니다.

이 스킬은 **추측이나 통계가 아닌 네이버쇼핑 검색엔진의 실측 패킷 데이터를 직접 추출**하여:
1. 카테고리 `relevance` 1.0(만점) 최적 경로를 판별하고,
2. 네이버 인덱서의 `terms`(형태소 색인어)와 공식 `relatedQueries`(연관검색어)를 실시간 추출하며,
3. 25~30자 상품명 5대 규칙과 terms 검증을 통과시킨 뒤,
4. 스마트스토어 20개 등록 폼 항목을 복사-붙여넣기 완성형으로 출력합니다.

## 🚀 주요 기능

### 1. 전용 Chrome 자동 런치 & 네이버 세션 연동
- 스크립트 실행 시 Chrome CDP(`http://127.0.0.1:9222`) 상태를 스스로 확인합니다.
- 크롬이 닫혀 있어도 전용 자동화 프로필(`%LOCALAPPDATA%\GJC\Chrome Automation`)로 **백그라운드에서 크롬을 자동 실행**하여 네이버 로그인 세션으로 실측 데이터를 안전하게 가져옵니다.

### 2. 카테고리 Relevance 실측 (적합도 만점 1.0)
- `python scripts/relevance.py "<키워드>"`
- 네이버 알고리즘이 부여한 category1 ~ category4의 실제 relevance를 소수점 6자리까지 실측하여 최적의 1.0 만점 경로를 추천합니다.
- *(예: '트레이닝복' 검색 시 여성의류 0.582999 > 남성의류 0.412883 실측 판별)*

### 3. 네이버 공식 연관검색어 & Terms 추출
- `python scripts/terms.py "<키워드>"`
- 네이버쇼핑 검색 결과의 공식 연관검색어 및 형태소 색인어(`categoryNNameIdxTerm`, `terms`)를 실시간 수집하여 노출 가능한 유효 키워드를 도출합니다.

### 4. 상품명 25~30자 최적화 & Terms 자동 검증
- `python scripts/terms.py "<키워드>" --title "<상품명안>"`
- **5대 작성 규칙:**
  1. 완성형 키워드 맨 좌측 배치
  2. 조합형 키워드 간격 축소
  3. 좌 → 우 순서 유지
  4. 공백 포함 **25~30자 (최대 35자 엄수, 초과 시 감점)**
  5. 중복 단어 0개 (최대 1회 제한)
- 설계한 상품명이 필수 terms를 빠짐없이 포함하는지 실시간 검증합니다.

### 5. 스마트스토어 20개 등록 폼 원스톱 출력
- 카테고리, 옵션, 가격, 재고, 1000×1000 대표이미지 가이드, 상세설명 섹션 구성, 상품고시, 배송비, 검색 태그 10개, SEO 설정(Title/Meta Description)까지 바로 등록할 수 있는 표 형태로 제공합니다.

## 📖 사용 방법

GJC(가재코드) 세션에서 아래와 같이 자연어로 지시하면 자동으로 파이프라인이 작동합니다:

```text
"네이버 등록해줘 이 URL https://detail.1688.com/offer/978504462463.html"
```
또는
```text
/skill:naver-seo-sudong-skill
상품 URL: https://detail.1688.com/offer/...
```

### 개별 스크립트 실행 (CLI)
```bash
cd scripts

# 1. 카테고리 실측
python relevance.py "자전거장갑"

# 2. 형태소 및 상품명 검증
python terms.py "자전거장갑" --title "자전거장갑 겨울 방한 라이딩 터치스크린 킥보드"

# 3. 통합 원클릭 파이프라인
python run_pipeline.py "자전거장갑" --title "자전거장갑 겨울 방한 라이딩 터치스크린 킥보드"
```

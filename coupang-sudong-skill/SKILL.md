# 쿠팡 윙(Wing) 상위노출 실전 컴퓨터 유즈(Computer Use) 등록 프로토콜

> **[필수 원칙: 더미 파일 / 모의 JSON 생성 절대 금지]**  
> 사용자가 쿠팡 등록을 요청했을 때 모의 JSON 파일(`CoupangWingListingPayload`)이나 복사-붙여넣기용 마크다운 텍스트만 출력하고 작업을 끝내는 것은 엄격히 금지된다.  
> 본 스킬은 **Orca Computer Use (`orca computer`)**를 사용하여 실제 Chrome 브라우저의 소싱 페이지를 읽고, 쿠팡 윙(Wing) 등록 화면에 직접 입력·제어하는 **실행형 자동화 스킬**이다.

---

## 0. 쿠팡 상위노출 5대 핵심 원칙 (네이버와의 차이점)

1. **상품명 60~90자 롱테일 고밀도 조합 (네이버 25~30자 제한 해제)**:
   - 네이버는 35자 초과 시 간소화 감점이지만, 쿠팡은 **최대 100자까지 수용**합니다.
   - [브랜드] + [핵심 상품명] + [소재/기능] + [용도/타겟] + [동의어 롱테일]을 결합하여 **60~90자 고밀도 상품명**으로 조합합니다.
2. **검색어 20개 풀장착 (네이버 10개 사전 제한 해제)**:
   - 쿠팡은 사전 등재 여부와 무관하게 **최대 20개(각 20자 이내)**의 검색어를 전부 노출 인덱스로 흡수합니다. 카테고리 맞춤형으로 빈칸 없이 20개를 꽉 채웁니다.
3. **카테고리별 동적 검색필터 속성(Attributes) 100% 매핑**:
   - 모바일 앱 필터 검색에 걸리려면 카테고리 필수/권장 속성이 반드시 채워져 있어야 합니다.
4. **상품정보제공고시 35개 군 정밀 매칭**:
   - 카테고리별 고시 항목 이름이 1글자만 달라도 차단됩니다. 소싱 데이터 스펙을 매핑하고 미확인 항목은 공식 허용 문구인 `'상세페이지 참조'`로 완벽 방어합니다.
5. **해외구매대행(`AGENT_BUY`) 안전 규칙 엄수**:
   - `pccNeeded: true` (개인통관고유부호 필수 수집), `emptyBarcode: true` (바코드 없음 사유: "해외구매대행 상품으로 바코드가 없습니다"), 출고소요일 **7~14일 설정** (국내 1~2일 설정 시 배송지연 패널티 방지).

## 1. 컴퓨터 유즈(Computer Use) 4단계 자동 등록 파이프라인

사용자가 상품 URL 또는 쿠팡 등록을 요청하면 다음 4단계를 즉시 자동 수행한다:

### 1단계: 활성 브라우저 소싱처 실시간 분석 (`orca computer`)
1. `orca computer list-windows --app chrome --json`으로 활성 Chrome 탭 및 소싱 창 확인.
2. `orca computer get-app-state --app chrome --restore-window --json`으로 현재 탭의 1688/타오바오 상세페이지 접근성 트리 및 스펙 확인.
3. 실제 공급단가(CNY), 제품명, 소재, 치수, 중량, 옵션(색상/사이즈), 대표 이미지 URL 전수 추출.

### 2단계: 20대 카테고리 디스패치 & 쿠팡 48개 필드 조립
추출된 실측 스펙을 바탕으로 시스템 스크립트를 호출하여 동적 메타데이터를 확정한다:
```bash
python ~/.gjc/skills/coupang-sudong-skill/scripts/run_coupang_pipeline.py
```
- **노출 카테고리 코드(`displayCategoryCode`)**: 20대 카테고리 엔진으로 즉시 분기.
- **60~90자 롱테일 상품명**: F자 시선 패턴 기반 브랜드 + 메인키워드 + 셀링포인트 조합.
- **검색어 태그 20개**: 해당 품목 전용 무중복 20개 태그 완벽 장착 (타 품목 태그 누출 0%).
- **가격 계산**: `(실공급원가 + 배송비 3,500원) / (1 - 마진율 0.35)` 기반 판매가 산출, 정상가는 판매가의 125%로 산출.
- **카테고리별 동적 속성(Attributes)**: 필수 속성 전수 매핑.
- **고시정보(Notices)**: 20대 품목군별 100% 실측 고시 생성.

### 3단계: 쿠팡 윙(Wing) 화면 직접 입력 및 조작 (`orca computer`)
Chrome에서 쿠팡 윙 상품등록 페이지(`https://wing.coupang.com/vendor/inventory/registration`)를 직접 조작한다.
1. `orca computer get-app-state --app chrome --restore-window --json`으로 쿠팡 윙 등록 폼 요소 인덱스 확인.
2. 11대 섹션별 자동 입력:
   - **노출 카테고리**: 카테고리 검색창 클릭 -> 코드 또는 카테고리명 입력 후 선택.
   - **등록상품명**: 60~90자 조합 상품명 주입 (`orca computer set-value` / `paste-text`).
   - **판매정보/가격**: 판매가, 정상가, 재고수량(999), 바코드 없음 사유 체크 ("해외구매대행 상품으로 바코드가 없습니다").
   - **옵션 입력**: 옵션 방식 선택 후 색상·사이즈 옵션 목록 및 가격/재고 일괄 적용.
   - **상품 이미지**: 대표 이미지(1000×1000) 및 추가 이미지 등록.
   - **상세설명**: 에디터 영역에 스토리보드 본문 HTML 입력.
   - **상품 주요정보**: 브랜드(자체제작/노브랜드), 제조사(협력업체), 원산지(중국).
   - **상품정보제공고시**: 카테고리 품목군 선택 후 각 세부 항목 입력.
   - **배송정보**: 배송방법 `구매대행 (AGENT_BUY)`, 개인통관고유부호(PCC) `필수 수집`, 출고소요일 `7일`, 배송비 `3,500원(또는 무료)`.
   - **반품/교환**: 반품배송비 `3,500원`, 초도반품비 `3,500원`, 반품주소지 선택.
   - **검색어 태그**: 검색어 입력창에 **20개 태그 전수 입력** (`orca computer set-value` / `paste-text` / `press-key Return`).
   - **검색필터 속성**: 카테고리 필수 속성값 드롭다운/입력 처리.

### 4단계: 등록 유효성 검사 및 완료 보고
1. 폼 필수값 누락 여부 검증 후 [저장/등록] 단계 진입.
2. 최종 등록 상태 및 노출 상품 ID 생성 여부를 화면에서 확인하여 사용자에게 보고.

## 3. 금지 사항 (위반 시 엄단)

- **더미 파일 생성 금지**: 더미 JSON 파일이나 복붙용 마크다운 텍스트만 만들고 끝내는 기만행위 금지.
- **타 품목 태그 누출 금지**: 자전거장갑 태그 등 특정 카테고리의 하드코딩 태그를 다른 품목에 절대 섞지 않는다.
- **국내 배송일자(1~2일) 설정 금지**: 해외구매대행 상품에 국내 배송일자를 설정하여 지연 패널티를 받는 실수를 원천 차단한다.
